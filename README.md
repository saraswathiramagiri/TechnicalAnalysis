# Technical Analysis Using R

BDA400 Technical Analysis using R assignment.

## Portfolio
The portfolio contains the following stocks:
- AAPL
- MSFT
- GOOG
- AMZN
- TSLA

## Files
- `portfolio.txt` - Contains the stock symbols used for the analysis.
- `technical_analysis.R` - Contains the R code for loading stock data, calculating statistics, technical indicators, and creating charts.

## Technical Indicators
The analysis includes:
- 20-day Simple Moving Average (SMA)
- 50-day Simple Moving Average (SMA)
- Relative Strength Index (RSI)
- MACD
- Bollinger Bands

## R Packages
- quantmod
- TTR
